# AGENTS.md — Mouse Manager

Инструкция для AI-агента. Читается в каждой сессии, поэтому держим её короткой.
Детали — в `docs/`.

## 1. Проект

Android-приложение для **переназначения боковых кнопок физической мыши** на системные
действия. Без root: `AccessibilityService` + `FLAG_REQUEST_FILTER_KEY_EVENTS`.
Целевое устройство — Xiaomi Pad 6 Pro. Интерфейс — русский.

Ключевой факт: боковые кнопки VXE R1SE+ приходят не как `BUTTON_BACK/FORWARD`, а как
клавиатурный аккорд `Ctrl+C` / `Ctrl+V` от устройства мыши (проверено, см. п.7).

## 2. Порядок работы

1. Прочитать `docs/PROJECT_STATUS.md` — это единственный источник истины о состоянии.

## 6. Жёсткие правила

- **S1 и S2 — замороженные эксперименты.** Не рефакторить, не «улучшать», не переносить
  файлы без отдельного подтверждения: это доказательная база.
- Ничего не устанавливать на планшет, не менять настройки ОС, не удалять файлы без
  явного подтверждения пользователя.
- Новая зависимость — только с обоснованием и проверкой `META-INF/com/android/build/
  gradle/aar-metadata.properties` (minCompileSdk, minAndroidGradlePluginVersion).
- Один модуль `:app`. Без Hilt/Koin/Room/navigation-compose, пока нет реальной нужды.
- `minSdk 29` — нужен `InputDevice.getDescriptor()`.
- `armed` **не хранить** в DataStore: при старте процесса и при подключении службы всегда
  `false` (D-006).
- Действия «вперёд» в v1 нет; не обещать в UI (D-021).
- UI-строки — в `res/values/strings.xml`, интерфейс на русском.
- **Никогда** не поглощать клавиши устройства, которого нет в списке целей.
- **Никогда** не поглощать модификаторы (`Ctrl`/`Shift`/`Alt`) — только клавишу аккорда.
- Любой глобальный перехват обязан быть fail-safe: нет конфига / ошибка / сервис не
  подключён → `return false` (пропустить).

## 7. Проверенные факты — не перепроверять

Всё измерено на устройстве, подробности в `docs/DECISIONS.md`.

1. Боковые кнопки VXE R1SE+ = `Ctrl↓ C↓ Ctrl↑ C↑` (или `V`), 4 события за ~120–180 мс.
   `ACTION_BUTTON_PRESS` с `BUTTON_BACK/FORWARD` не приходит вообще.
2. `InputDevice.descriptor` мыши стабилен между переподключениями
   (`ce5035b0dc81cc3d25dbb6f30e5e51d03dcb3992`), а `deviceId` меняется каждый раз
   (наблюдали 19 → 25 → 27 → 29 → 30 → 31). Идентифицировать мышь только по descriptor.
3. `canRequestFilterKeyEvents` + `FLAG_REQUEST_FILTER_KEY_EVENTS` работает на HyperOS 3:
   `flags=0x20`, ключи реально приходят в `onKeyEvent` и гасятся.
4. `adb shell input` (инъекция) **не видна** фильтру: такие события не попадают в
   `onKeyEvent`. Автотесты перехвата через adb невозможны.
5. Клавиши других устройств (`gpio-keys`, `pmic_resin`) приходят с
   `PASSED_OTHER_DEVICE` и работают штатно (громкость менялась 0 → 10).
   **Полноценная клавиатура (чехол/Bluetooth) не проверялась** — нет железа. Это
   непроверенное условие: `VOLUME_UP/DOWN` доказывают фильтрацию по устройству, но не
   совместимость с буквами, модификаторами, IME и сочетаниями. См. `PROJECT_STATUS.md` §6.
6. Средняя кнопка — это `ACTION_BUTTON_PRESS` с `BUTTON_TERTIARY` (MotionEvent), мимо
   `onKeyEvent`. Левая/правая — `BUTTON_PRIMARY`/`BUTTON_SECONDARY`.
7. `AccessibilityService.onMotionEvent` + `setMotionEventSources()` **забирает** события у
   системы (нет режима «посмотреть и передать дальше») → обычные кнопки не переназначить
   без поломки курсора. См. D-012.

## 8. Как проверять на устройстве

1. Собрать, установить, запустить.
2. Включить службу: Настройки → Специальные возможности → «Mouse Manager».
3. Проверить в приложении: служба подключена, флаг фильтра принят.
4. Выбрать целевое устройство, включить перехват.
5. Нажать боковую кнопку → в журнале `CONSUMED`, действие выполнилось.
6. Проверить, что кнопки громкости работают → `PASSED_OTHER_DEVICE`. Полноценную
   клавиатуру проверить отдельно, когда появится железо (непроверенное условие).
7. Переподключить мышь → descriptor тот же, привязка не слетела.
8. Перезапустить приложение/службу → `armed=false`, перехват не восстановился сам (D-006).

## 9. Экономия токенов

- Новая задача = `/clear` (или новая сессия). Контекст не тащить между задачами.
- `/compact` — когда контекст перевалил за половину, и только между задачами, не внутри.
- После компакта перечитать `AGENTS.md` + `docs/PROJECT_STATUS.md`: это долговременная
  память, остальное можно не восстанавливать.
- В запросе указывать конкретные файлы («посмотри `domain/RemapEngine.kt`»), а не
  «разберись в проекте».
- Не читать `spikes/` и не прогонять сборку «на всякий случай».
- Скриншоты и большие логи — только когда без них нельзя.

Подробно: `docs/WORKFLOW.md`.
