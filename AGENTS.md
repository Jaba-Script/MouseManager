# AGENTS.md — Mouse Manager

Инструкция для AI-агента. Читается в каждой сессии, поэтому здесь только то, что нужно
всегда. Детали — в `docs/`, по таблице ниже.

## 1. Проект

Android-приложение для **переназначения боковых кнопок физической мыши** на системные
действия. Без root: `AccessibilityService` + `FLAG_REQUEST_FILTER_KEY_EVENTS`.
Целевое устройство — Xiaomi Pad 6 Pro. Интерфейс русский, строки в `res/values/strings.xml`.

Ключевой факт: боковые кнопки VXE R1SE+ приходят как аккорд `Ctrl+C` / `Ctrl+V` от
устройства мыши, а не как `BUTTON_BACK/FORWARD`.

## 3. Жёсткие правила

- S1 и S2 — **замороженные эксперименты** (`spikes/`): не рефакторить, не переносить,
  не «улучшать» без отдельного подтверждения.
- Ничего не устанавливать на планшет, не менять настройки ОС, не удалять файлы и не делать
  коммит без явного подтверждения пользователя.
- Новая зависимость — только с обоснованием и проверкой
  `META-INF/com/android/build/gradle/aar-metadata.properties` (minCompileSdk, minAGP).
- Один модуль `:app`. Без Hilt/Koin/Room/navigation-compose, пока нет реальной нужды.
- `minSdk 29` — нужен `InputDevice.getDescriptor()`.
- `armed` **не хранить** в DataStore: при старте процесса и подключении службы всегда
  `false` (D-006).
- Действия «вперёд» в v1 нет; не обещать его в UI (D-021).
- **Никогда** не поглощать клавиши устройства, которого нет в списке целей.
- **Никогда** не поглощать модификаторы (`Ctrl`/`Shift`/`Alt`) — только клавишу аккорда.
- Поглощённый DOWN всегда получает поглощённые парные события: UP и повторный DOWN/repeat
  при наличии pending — `Consume` до `armed`/`targets` (D-026).
- В продуктовой конфигурации — только одна служба с `FLAG_REQUEST_FILTER_KEY_EVENTS`;
  не включать S2 одновременно с продуктом (D-025).
- Любой глобальный перехват обязан быть fail-safe: нет конфига / ошибка / служба не
  подключена → `return false` (D-018).
- Не перепроверять факты из `PROJECT_STATUS.md` §2 и `SPIKES.md`: они измерены на устройстве.

## 4. Команды

```powershell
# сборка
Set-Location "<путь-к-репозиторию>"; .\gradlew.bat :app:assembleDebug --no-daemon --console=plain

# установка (только с разрешения пользователя)
& "$env:ANDROID_HOME\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk

# лог приложения (единый тег)
& "$env:ANDROID_HOME\platform-tools\adb.exe" logcat -d -s MouseManager:D

# скриншот
& "$env:ANDROID_HOME\platform-tools\adb.exe" exec-out screencap -p > shot.png
```

Окружение (JDK, SDK, версии, adb) — `PROJECT_STATUS.md` §3. Спайки собираются отдельно
из `spikes/s1` и `spikes/s2`.

## 5. Задача выполнена, когда

1. Поведение соответствует `ARCHITECTURE.md` и принятым ADR.
2. Сборка проходит; для UI-задач — проверено на устройстве, если это требуется.
   Чек-лист M1/S7 — `docs/S7-DEVICE-CHECKLIST.md`; чек-лист M2 —
   `ARCHITECTURE.md` §16.2.
3. `docs/PROJECT_STATUS.md` обновлён; новое решение записано как D-0NN в `DECISIONS.md`.
